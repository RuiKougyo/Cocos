# 無料版の導入手順（Google スプレッドシート + Apps Script + Cloudflare Pages）

費用は **0円** です。必要なのは「店舗用の Google アカウント」と「Cloudflare の無料アカウント」の2つだけです。

| 作業 | 誰が | 回数 | 目安 |
| --- | --- | --- | --- |
| A. データ置き場（スプレッドシート）を作る | 導入担当者 | 最初の1回 | 15分 |
| B. 画面を公開する | 導入担当者 | 最初の1回 | 15分 |
| C. 店長の初期設定 | 店長（スマホ） | 最初の1回 | 5分 |
| D. 毎月の運用 | 店長（スマホ） | 毎月 | 1分 |

> A と B は画面が細かいので **パソコンでの作業をおすすめ** します（スマホのブラウザを「PC版サイト」表示にすれば可能です）。C 以降はすべてスマホで完結します。
> Google や Cloudflare の画面の文言は変わることがあります。見当たらない場合は近い名前のボタンを探してください。

---

## A. データ置き場（スプレッドシート）を作る

### A-1. 店舗用の Google アカウントを用意する
- 個人のアカウントではなく、**店舗専用のアカウント**（無料の Gmail で可）を作ってください。店長が交代しても引き継げます。
- **2段階認証を必ず有効にしてください**（Google アカウント → セキュリティ → 2段階認証プロセス）。このアカウントに入られると全データが見えてしまうためです。

### A-2. スプレッドシートを作る
1. 店舗用アカウントで [Google スプレッドシート](https://sheets.google.com) を開き、「空白のスプレッドシート」を作成する
2. 名前を「シフト管理（店舗名）」などに変える
3. **このスプレッドシートは誰とも共有しないでください**（共有すると全員分のデータが見えてしまいます）

### A-3. プログラム（Apps Script）を貼り付ける
1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
2. 左の「プロジェクトの設定」（歯車）→「『appsscript.json』マニフェスト ファイルをエディタで表示する」に**チェック**
3. 左の「エディタ」（`< >`）に戻る
4. `コード.gs`（または `Code.gs`）の中身を**すべて消して**、このリポジトリの [`gas/Code.gs`](../gas/Code.gs) の中身を**すべて貼り付け**
5. `appsscript.json` の中身をすべて消して、[`gas/appsscript.json`](../gas/appsscript.json) の中身を貼り付け
6. 上部の 💾（保存）を押す

### A-4. 初期化する（initialize を実行）
1. 上部の関数の選択欄で **`initialize`** を選び、「▷ 実行」を押す
2. 「承認が必要です」→「権限を確認」→ 店舗用アカウントを選ぶ
3. 「このアプリは Google で確認されていません」と出たら、「詳細」→「（プロジェクト名）（安全ではないページ）に移動」→「許可」
   - 自分で作った（貼り付けた）プログラムなので、この表示は正常です
4. 下の「実行ログ」に **`初期設定コード: XXXXXXXXXXXX`** と表示されます → **メモしておく**（C で使います）
5. スプレッドシートに `members` `periods` などのシートが作られていることを確認

### A-5. ウェブアプリとして公開（デプロイ）
1. 右上の「デプロイ」→「新しいデプロイ」
2. 「種類の選択」（歯車）→「ウェブアプリ」
3. 次のように設定して「デプロイ」
   - 説明: `シフト管理`
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 表示された **ウェブアプリの URL（`https://script.google.com/macros/s/……/exec`）をコピー** しておく（B で使います）

> 「全員」にしても、スプレッドシート自体が公開されるわけではありません。画面からの問い合わせにプログラムが答えるだけで、何を返すかはプログラム側で厳密に制限しています（スタッフは自分の提出と、他の人の名前・時間帯だけ）。

## B. 画面を公開する（Cloudflare Pages）

### B-1. Cloudflare のアカウントを作る
[Cloudflare](https://dash.cloudflare.com/sign-up) で無料アカウントを作成します（クレジットカードは不要）。

### B-2. GitHub のリポジトリから公開する（おすすめ）
1. Cloudflare のダッシュボード →「Workers & Pages」→「作成」→「Pages」→「Git に接続」
2. GitHub と連携し、このリポジトリを選ぶ
3. ビルドの設定:

   | 項目 | 値 |
   | --- | --- |
   | フレームワーク | なし（None） |
   | ビルドコマンド | `npm ci && npm run build` |
   | ビルド出力ディレクトリ | `dist` |
   | ルートディレクトリ | `app` |

4. 「環境変数」に次の2つを追加:

   | 変数名 | 値 |
   | --- | --- |
   | `VITE_BACKEND` | `gas` |
   | `VITE_GAS_URL` | A-5 でコピーした URL（`…/exec`） |

5. 「保存してデプロイ」→ 数分で `https://（名前）.pages.dev` が発行されます

> パソコンで `app/` をビルドして、できた `dist` フォルダを「直接アップロード」する方法でも公開できます（`app/.env` に上の2つを書いてから `npm run build`）。

## C. 店長の初期設定（スマホで）

1. スマホで **`https://（名前）.pages.dev/#/admin`** を開く
2. 「初期設定」画面で入力:
   - 初期設定コード（A-4 でメモしたもの）
   - 店舗名
   - 店長用パスワード（10文字以上）
3. 「認証アプリの登録」画面:
   - 認証アプリ（Google Authenticator など、無料）を入れておく
   - 「認証アプリに登録する」を押す → 認証アプリが開いて登録される
   - 開かない場合は「キーをコピー」→ 認証アプリの「セットアップキーを入力」に貼り付け
   - 認証アプリに表示された6桁のコードを入力して「確認」
4. 「メンバー・設定」→「＋ 期間を作成」（例: 10月前半、10/1〜10/15）→ 状態を「受付中」にする
5. この画面をホーム画面に追加しておくと、次から1タップで開けます

---

## D. 毎月の運用（店長・スマホ）

1. 「メンバー・設定」→「＋ 期間を作成」→「受付中」にする
2. 「募集文をコピー」→ **グループチャットに貼る**（URL は毎月同じ）
3. 初めてのスタッフがいれば「参加申請」を承認する
4. 締切後は「タイムライン」で希望を見て、バーをタップして確定。「未提出」タブの「催促文をコピー」で催促もできます

スタッフ側は、URL を開いて提出するだけです。休みたい日は同じ URL の「代わりを探す」から、入れる人を確認できます。

## 困ったとき

| 状況 | 対処 |
| --- | --- |
| 店長のパスワード・認証アプリが分からなくなった | Apps Script で関数 **`resetAdmin`** を実行 → 実行ログの新しい初期設定コードで C をやり直す（スタッフやシフトのデータは消えません） |
| スタッフが PIN を忘れた・ロックされた | 店長画面「メンバー・設定」→ その人の「管理」→「ログインをリセット」 |
| グループ以外に URL が漏れた | 「メンバー・設定」→「URLが店外に漏れたとき」→「URLを再発行」→ 新しい募集文をグループに貼る |
| プログラム（Code.gs）を更新した | Apps Script で貼り替えて保存 →「デプロイ」→「デプロイを管理」→ 鉛筆アイコン →「バージョン: 新しいバージョン」→「デプロイ」（URL は変わりません） |
| 間違ってデータを消した | スプレッドシートの「ファイル」→「変更履歴」から過去の状態に戻せます（Google が自動で保存） |
| 画面に「混み合っています」と出る | 数秒待ってもう一度。通常は自動で再送されます |

## 無料で使える範囲（目安）

| サービス | 無料枠 | この用途での見込み |
| --- | --- | --- |
| Google Apps Script | 同時処理 30 件まで、1回の処理は 6 分まで ほか | 1店舗・数十人なら十分 |
| Google スプレッドシート | 1ファイル 1,000 万セル | 数年分でも十分（古いデータは自動削除） |
| Cloudflare Pages | 帯域無制限、ビルド 月 500 回 | 十分 |

制限値は各社の都合で変わることがあります。

## セキュリティ上の約束ごと

- スプレッドシートと Apps Script は **誰とも共有しない**（店舗用アカウントだけが持つ）
- 店舗用アカウントの **2段階認証を有効にする**
- 店長用パスワードと認証アプリは店長だけが持つ（交代時は `resetAdmin` で入れ替える）
- PIN・パスワードはハッシュ化して保存しているため、シートを見ても元の値は分かりません
